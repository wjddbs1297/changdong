# 동아리 활동 랭킹

- 관리자 메뉴: `/admin-ranking`. 연도별 기본, 월별 선택.
- 종료된 예약 중 `Completed` 또는 활동내용이 있는 일지만 집계.
- 예약 1건 = 1회. 활동시간은 순위에 영향을 주지 않음.
- 인원은 초등/중등/고등/24세 이하 남녀 8칸의 합계, 매회 합산한 연인원.
- 인원이 비어 있는 과거 기록은 0명. 예정 인원을 실제 인원으로 대체하지 않음.
- 횟수와 인원 각각 내림차순 경쟁 순위(1, 1, 3). 두 순위 합계를 오름차순 경쟁 순위로 계산.
- 활동 0회는 순위 없음. 공동 1위는 모두 표시.
- 활성 동아리만 포함. 관리자, Daily/데일리, TEST, 방과후 초등/중등 제외.
- `ing`와 `-ing`, `ABLE/에이블`과 `ABLE2026`은 기존 동아리 별칭으로 합산.

## Google Sheets

기존 예약 관리 문서의 `2026_동아리랭킹` 탭, gid `944991703`.
기존 예약내역/Users/Members는 변경하지 않고 새 탭에 수식으로 연결.

- B1: 2026년 고정. 프로그램 참여 표시가 연간 기록이므로 다른 연도로 바꾸지 말 것.
- B2: 활동 월. 0은 연간 전체, 1~12는 해당 월. 프로그램 참여는 월과 무관한 연간 표시.
- 5행: 머리글, 6행부터 동아리별 데이터.
- A: 동아리명, B: 횟수, C: 연인원, D/E: 개별 순위, F: 합계, G: 종합순위, H: 가장 활발한 동아리.
- I~M: 상상충전200%, 상상나들이, 달맞이 루프탑, GNCS페스티벌, 찬조공연.
- 참여 프로그램에는 `○`, 미참여는 빈칸. N열은 `=COUNTIF(I6:M6,"○")`를 행별로 적용.
- O: 계정ID. 이름만 변경해도 집계 대상이 바뀌지 않도록 별도 키 유지.
- B~H/N은 수식 경고 보호. I~M 직접 입력은 보존됨.
- 신규 동아리는 100행 이내 빈 행에 기존 행 전체를 복사하고 A/O를 변경한 후 I~M의 복사된 참여 표시를 비울 것. 필터 범위도 확장할 것.
- 내년에는 연도별 별도 탭을 준비하고 해당 연도 프로그램 표시를 빈칸으로 시작. 기존 탭의 연도를 바꿔 재사용하지 말 것.

프로그램 점수 기준은 미정이므로 참여 프로그램 수는 현재 종합순위에 합산하지 않음.
