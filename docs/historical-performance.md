# 2026년 상반기 이관 실적

원본: 담당자가 제공한 `2026년 동아리실적.xlsx`의 1~6월 B5:O32 본표.
연도는 담당자가 2026년으로 확인함. 하단 별도 표와 분기·연간 합계는 가져오지 않음.
청온화, 자운고, 베리어스 제외. 안골마을은 안골밴드, ABLE은 ABLE2026, ING는 -ing로 연결.

기존 관리 스프레드시트의 `과거월별실적` A:R에 보관한다.
연도, 월, 계정ID, 원본명, 활동횟수, 남, 여, 원본의 10개 성별 시간대 인원, 원본 셀 위치 순서다.
횟수 공란은 미기재이며 0회로 확정하지 않는다. 랭킹은 확인된 횟수 기준 잠정 순위라고 안내한다.
데일리 자료는 보관하지만 기존 정책대로 동아리 실적·랭킹에서는 제외한다.
방과후밴드 자료는 월별 이용 실적에 원본 이름으로 표시하고 랭킹에서는 제외한다.

월·분기·연 합계에 포함한다. 날짜·시간·교급·참여자 명단을 추정하지 않으며 예약이나 일지를 만들지 않는다.
주별 집계에는 배분하지 않는다. 원본 평일 오전 경계는 14시이고 공휴일 오전·오후 구분은 없으므로 기존 13시 경계 예약 통계와 별도의 원본 인원 상세로 표시한다.
사이트에서는 동일 동아리·월의 예약을 이관 합계와 중복 합산하지 않는다. 7월 이후 기록은 그대로 둔다.
